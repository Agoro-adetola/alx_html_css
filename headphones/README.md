# Designer Webpage

This project is a fully responsive and accessible webpage built from scratch using only HTML and CSS. It replicates a design created by Nicolas Philippot, UI/UX designer.

## 🚫 Restrictions
- No external CSS frameworks (e.g., Bootstrap)
- No JavaScript
- No libraries

## 🎯 Objective
Create a pixel-perfect implementation of the Figma design using semantic HTML and modern CSS techniques.

## 📐 Features
- Responsive layout (mobile version activates at 480px)
- Accessible navigation and content
- Custom fonts: Source Sans Pro and Spin Cycle OT
- Hover/active styles for links and buttons
- Max content width: 1000px centered
